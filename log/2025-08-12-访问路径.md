
⏺ 🌐 Palm AI 三套系统访问路径

  📍 访问路径说明

  1. Flow System - 复杂 React 状态管理 + 动画效果

  /{locale}/palm/flow/{step}

  示例：
  - 英文版：/en/palm/flow/0
  - 中文版：/zh-HK/palm/flow/0
  - 日文版：/ja/palm/flow/0
  - 西班牙语：/es/palm/flow/0

  步骤范围：0-20

  2. Stable System - 服务端渲染 + 1:1 HTML 还原 + Server Actions

  /{locale}/palm/stable/{step}

  示例：
  - 英文版：/en/palm/stable/0
  - 中文版：/zh-HK/palm/stable/0
  - 日文版：/ja/palm/stable/0
  - 西班牙语：/es/palm/stable/0

  步骤范围：0-20

  3. Simple System - 纯 HTML 直接渲染（最轻量）

  /{locale}/palm/simple/{step}

  示例：
  - 英文版：/en/palm/simple/0
  - 中文版：/zh-HK/palm/simple/0
  - 日文版：/ja/palm/simple/0
  - 西班牙语：/es/palm/simple/0

  步骤范围：0-20

  📊 三套系统对比

  | 特性   | Flow System                     | Stable System
  | Simple System |
  |------|---------------------------------|------------------------------------|-
  --------------|
  | 路径前缀 | /palm/flow/                     | /palm/stable/
    | /palm/simple/ |
  | 技术栈  | React + Zustand + Framer Motion | Server Components + Server Actions
   | 纯 HTML 渲染     |
  | 状态管理 | 客户端复杂状态                         | URL 参数 + 服务端状态
                  | 无状态           |
  | 动画效果 | 丰富的 Framer Motion 动画            | CSS 动画
           | 原始 HTML 动画    |
  | 性能   | 中等（客户端渲染）                       | 高（服务端渲染）
                   | 最高（静态 HTML）   |
  | SEO  | 较差                              | 优秀
    | 优秀            |
  | 适用场景 | 需要复杂交互和动画                       | 稳定生产环境使用
                     | 轻量级或降级方案      |
